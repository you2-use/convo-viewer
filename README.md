# 콘보모드 뷰어 설정

Marinara Engine의 **콘보(Conversation) 채팅방마다 말풍선·글꼴·배경을 다르게 꾸미는 확장**입니다. 마음에 드는 설정은 프리셋으로 보관하고 다른 콘보방에 적용할 수 있습니다.

- **공개 버전:** v1.3.0
- **작업 기준:** Marinara Engine v2.5.0에서 제작·작업했습니다. 다른 엔진 버전과 모든 사용자 테마의 호환성을 보장하지 않습니다.
- **설치 방식:** GitHub 확장 관리자 또는 ZIP 직접 설치
- **확장 이름:** 콘보모드 뷰어 설정

[설치용 ZIP 다운로드](https://github.com/you2-use/convo-viewer/releases/download/v1.3.0/convo-viewer.personal-extension.zip) · [v1.3.0 릴리스](https://github.com/you2-use/convo-viewer/releases/tag/v1.3.0)

## 주요 기능

- 내 메시지와 상대 메시지의 글자색·말풍선 배경색·테두리를 각각 설정합니다.
- 말풍선 모양을 원형·사각형·물방울형으로 고르고, 일반 텍스트의 줄바꿈을 말풍선으로 나누어 표시합니다.
- Marinara에 등록된 글꼴과 글자 크기를 선택하고, 입력창에도 같은 글꼴을 적용할 수 있습니다.
- 방별 배경색·사진·사진 표시 정도, 상단바 숨기기, 캐릭터 아바타 숨기기를 설정합니다.
- 설정을 프리셋으로 저장·수정·가져오기·내보내기 할 수 있습니다.
- 데스크톱에서는 뷰어 버튼 이동, 창 이동·크기 조절, 채팅 설정에 넣기·꺼내기를 제공합니다. 좁은 화면에서는 채팅 도구 메뉴를 사용합니다.

엔진 소스를 수정하거나 npm 설치·컴파일을 할 필요가 없습니다.

## 설치 전 준비

두 방법 모두 Marinara에서 외부 확장을 허용해야 합니다. 이미 외부 확장을 사용하고 있다면 설치 단계로 넘어가세요.

1. 서버에서 외부 확장이 잠겨 있다면 Marinara 설치 폴더의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정한 뒤 Marinara를 재시작합니다. 다른 사람이 운영하는 서버라면 운영자에게 요청하세요.
2. **설정 → 고급 → 위험 구역(Settings → Advanced → Danger Zone)** 에서 **타사 확장 가져오기 허용(Allow third-party extension imports)** 을 켭니다.
3. **설정 → 애드온 → 외부 확장(Settings → Addons → External Extensions)** 을 엽니다.

휴대폰·LAN·원격 주소에서 확장을 관리할 때 관리자 접근을 요구하면, 운영자가 설정한 `ADMIN_SECRET` 값을 **설정 → 고급 → 관리자 접근(Admin Access)** 에 입력해야 합니다. 이 확장에 별도 API 키나 GitHub 토큰을 입력할 필요는 없습니다. 언어 팩에 따라 메뉴 일부가 영어로 표시될 수 있습니다.

가져온 확장은 꺼진 상태로 저장됩니다. **코드와 요청 권한을 검토하고 실행을 승인해야** 사용할 수 있습니다.

## 설치 방법 1: GitHub 확장 관리자

GitHub 확장 관리자가 설치되어 있고 켜져 있을 때 사용할 수 있습니다.

1. 관리자에서 **확장 추가**를 누릅니다.
2. 저장소 주소 입력란에 다음 주소를 붙여 넣습니다.

   ```text
   https://github.com/you2-use/convo-viewer
   ```

3. **패키지 찾기**를 누릅니다.
4. 저장소 루트의 **manifest.json**을 선택하고 **내용 확인**을 누릅니다. 릴리스 첨부 ZIP 대신 이 manifest를 선택하는 방법을 기본으로 권장합니다.
5. 이름이 **콘보모드 뷰어 설정**, 버전이 **v1.3.0**, 실행 방식이 브라우저(client)인지 확인한 뒤 **설치**를 누릅니다.
6. **검토 후 켜기** 또는 Marinara의 **검토 및 실행(Review and run)** 에서 JS·CSS와 **전체 페이지 접근(Full page access)** 권한을 검토합니다. 표시된 코드의 실행을 승인해 확장을 켭니다.

공개 저장소이므로 설치하는 사람은 **GitHub 로그인이나 토큰 없이** 파일을 받을 수 있습니다. 이 저장소 연결로 이후 업데이트도 확인합니다.

## 설치 방법 2: ZIP 다운로드 후 직접 설치

1. [설치용 ZIP 다운로드](https://github.com/you2-use/convo-viewer/releases/download/v1.3.0/convo-viewer.personal-extension.zip)를 눌러 `convo-viewer.personal-extension.zip`을 받습니다.
2. **ZIP을 미리 풀지 마세요.** Marinara에서 **설정 → 애드온 → 외부 확장 → 확장 파일 가져오기(Import Extension File)** 를 누릅니다.
3. 다운로드한 ZIP을 선택합니다.
4. 이름 **콘보모드 뷰어 설정**과 버전 **v1.3.0**을 확인하고 가져오기를 완료합니다.
5. **검토 및 실행(Review and run)** 을 열어 코드와 **전체 페이지 접근** 권한을 확인한 뒤 실행을 승인합니다.

GitHub 확장 관리자가 기본 가져오기 버튼을 숨겼다면 관리자의 **확장 추가 → 파일에서**로 같은 ZIP을 선택할 수 있습니다. ZIP 직접 설치 후 GitHub 업데이트 확인을 사용하려면 관리자에서 이 저장소를 별도로 연결해야 합니다.

GitHub 자동 생성 **Source code** ZIP 대신 위의 설치용 ZIP을 사용하세요. 릴리스 첨부 파일을 관리자가 가져오지 못할 때는 방법 1의 저장소 주소와 `manifest.json`을 선택하세요.

## 실제 사용 순서와 버튼 위치

1. **콘보(Conversation) 채팅방**을 엽니다. RP·Game 화면에서는 뷰어 버튼이 표시되지 않습니다.
2. 데스크톱에서는 채팅 영역에 떠 있는 **콘보모드 뷰어 설정** 아이콘을 누릅니다. 마우스를 올리면 이름이 표시됩니다. 버튼은 드래그하거나 초점을 둔 뒤 방향키로 이동할 수 있으며 방별 위치를 기억합니다.
3. 좁은 화면에서는 **채팅 도구(…) → 콘보모드 뷰어 설정**을 누릅니다. 기본 도구 메뉴가 없으면 확장의 보조 `…` 버튼이 표시됩니다.
4. **이 방에서 뷰어 사용**을 켠 상태에서 **테마 / 텍스트 / 배경** 탭을 선택합니다.
5. 옵션을 바꾸거나 **뷰어 프리셋**을 선택해 화면을 미리 봅니다.
6. 창 본문 아래쪽의 **적용**을 눌러 **현재 방 설정을 저장**합니다. 내용이 길면 창 안을 아래로 스크롤하세요.

창 제목을 드래그하면 창을 옮길 수 있고, 데스크톱에서는 오른쪽 아래 크기 조절 영역으로 크기를 바꿀 수 있습니다. 창의 **채팅 설정에 넣기** 아이콘을 누르면 Marinara의 채팅 설정 안에 같은 이름의 항목으로 들어갑니다. 도킹된 뒤에는 **채팅 설정**을 열어 사용하고, **채팅 설정에서 꺼내기** 아이콘으로 다시 분리합니다. 도킹 상태·버튼 위치·창 크기는 방별로 저장됩니다.

## 적용·저장·덮어쓰기의 차이

| 조작 | 실제 동작 |
| --- | --- |
| 옵션 변경·프리셋 선택 | 현재 화면에 미리 보여 줍니다. 아직 방 설정으로 저장하지 않습니다. |
| **적용** | 현재 방의 뷰어 설정 전체를 지금 미리 보는 값으로 저장합니다. 다른 방에는 적용하지 않습니다. Marinara의 별도 저장 버튼은 필요 없습니다. |
| **닫기(×)**·Escape | 적용하지 않은 미리보기를 버리고 마지막으로 저장한 방 설정으로 돌아갑니다. 이미 저장한 프리셋·배치·업로드 사진은 되돌리지 않습니다. |
| **이 방에서 뷰어 사용** 끄기 → 적용 | 이 방에 뷰어 꾸미기를 사용하지 않도록 저장합니다. |
| **초기화** | 확인 후 현재 방에 저장된 뷰어 설정을 제거하고 기본값으로 돌아갑니다. 다른 방·프리셋·배경 라이브러리·창 배치는 유지합니다. |
| 프리셋 **저장** 아이콘 | 선택한 프리셋 전체를 현재 미리 보는 설정으로 **덮어씁니다**. 방에 저장하려면 별도로 적용을 누릅니다. |
| **새 프리셋** 아이콘 | 현재 미리 보는 설정을 새 이름으로 바로 저장합니다. |
| 프리셋 **수정** 아이콘 | 이름을 바꿉니다. Enter 또는 다른 곳 클릭으로 저장하고 Escape로 취소합니다. |
| 프리셋 **삭제** 아이콘 | 확인 후 선택한 프리셋만 삭제합니다. 이미 방에 적용한 설정은 유지합니다. |
| **새 배경 사진 올리기** | 파일을 선택하는 순간 현재 Marinara 서버의 배경 라이브러리에 **원본 사진을 업로드**합니다. 방 배경으로 저장하려면 적용도 눌러야 합니다. 창을 닫아도 업로드 파일은 남습니다. |

프리셋 작업은 선택창 아래의 아이콘으로 표시됩니다. 마우스를 올리면 **저장 / 수정 / 새 프리셋 / 프리셋 가져오기 / 프리셋 내보내기 / 삭제** 이름을 확인할 수 있습니다.

내보내기는 **선택한 프리셋 하나**를 `.convo-viewer-preset.json`으로 받습니다. 가져오기는 기존 목록에 추가하며, 같은 이름·잘못된 항목·저장 한도를 넘은 항목은 덮어쓰지 않고 건너뜁니다. 새 프리셋은 배경 사진 참조를 제외하고 저장합니다. 가져온 프리셋에 사진 참조가 있다면 같은 서버에 그 사진이 있어야 표시됩니다. 사진 파일 자체는 JSON에 포함하지 않습니다.

말풍선과 배경을 빠르게 꾸밀 수 있는 **추천 프리셋 5종**입니다.

[추천 프리셋 5종 ZIP 다운로드](https://github.com/you2-use/convo-viewer/releases/download/v1.3.0/simple_preset.zip)

| 카톡 | 노란색·흰색 말풍선, 회청색 배경, 사각형 | `kakao.convo-viewer-preset.json` |
| 카톡다크 | 노란색·짙은 회색 말풍선, 어두운 배경, 사각형 | `darkkakao.convo-viewer-preset.json` |
| DM | 보라색·밝은 회색 말풍선, 흰 배경, 물방울형 | `DM.convo-viewer-preset.json` |
| 비트윈 | 민트색·흰색 말풍선, 연한 회녹색 배경, 원형 | `between.convo-viewer-preset.json` |

### 프리셋 가져오기

1. 위 링크에서 `simple_preset.zip`을 받습니다. **이 파일은 확장 설치용 ZIP이 아니므로 먼저 압축을 풉니다.**
2. 확장이 켜진 상태에서 콘보방의 **콘보모드 뷰어 설정**을 엽니다.
3. **뷰어 프리셋** 선택창 아래의 **프리셋 가져오기** 아이콘을 누릅니다.
4. 압축을 푼 파일 중 원하는 `.convo-viewer-preset.json` 파일 하나를 선택합니다. 다른 프리셋도 필요하면 같은 방법으로 각각 가져옵니다.
5. 선택창에서 가져온 프리셋을 골라 미리 본 뒤, 본문 아래 **적용**을 눌러 현재 방에 저장합니다.

다섯 프리셋 모두 글자 크기는 **15px**, **줄바꿈마다 분리**는 켜짐이며, 글꼴은 현재 테마를 따릅니다. 배경 사진은 포함하지 않습니다. 프리셋을 선택하면 말풍선·텍스트·배경 설정 전체를 불러오므로 현재 꾸미기를 보관하려면 먼저 **새 프리셋**으로 저장하세요. 같은 이름의 프리셋이 이미 있으면 가져오기에서 건너뜁니다.

## 설정별 안내와 제한

- **말풍선:** 내/상대 글자색과 배경색을 따로 지정합니다. 색상 옆 선택을 끄면 테마 색을 따릅니다. 배경색·모양 등 말풍선 표현은 Marinara의 **Bubbles** 표시 방식에서 확인하세요.
- **테두리:** 테마 따르기·없음·직접 설정, 실선·점선·파선과 두께 0.1~10pt를 선택합니다.
- **줄바꿈마다 분리:** 화면상의 표시만 바꾸며 원본 메시지를 나누어 저장하지 않습니다. 링크·이미지·코드·강조 등 서식이 있는 메시지, 생성 중 메시지, 엔진이 이미 나눈 여러 화자 말풍선 등은 분리하지 않습니다.
- **텍스트:** Marinara에 등록된 글꼴을 선택합니다. 글자 크기는 12~32px이며 **인풋창에 글꼴 적용하기**로 입력창 글꼴도 바꿀 수 있습니다. 글꼴 설치·다운로드 기능은 이 확장에 포함되지 않습니다.
- **배경:** Marinara 배경 라이브러리 사진을 선택하거나 JPG·PNG·GIF·WebP·AVIF를 올립니다. 확장 업로드 한도는 **20 MiB**이며 서버 정책에 따라 더 제한될 수 있습니다. 사진 표시 수치가 0%면 보이지 않고 100%면 가장 진하게 표시됩니다.
- **상단바 숨기기:** 이 콘보방에서 상단바를 숨깁니다. 화면 위쪽 48px 안의 버튼이 아닌 빈 곳을 클릭하면 약 6초 동안 다시 표시합니다.
- **캐릭터 아바타 숨기기:** 캐릭터 아바타·캐릭터 메시지 번호와 관련 여백을 숨깁니다. 사용자 아바타와 원본 메시지 데이터는 유지합니다. 기본값은 꺼짐입니다.
- **프리셋:** 이름 1~40자, 최대 40개, 가져오기 JSON 최대 **1 MiB**입니다. 지원 형식은 이 확장의 `marinara.conversation-viewer-presets` 형식 버전 1입니다. 일반 JSON·다른 확장 프리셋은 지원하지 않습니다.
- 방 설정은 최대 500개를 정규화하며, 확장 전용 저장소에도 엔진의 용량 제한이 있습니다. 무제한 저장을 지원하지 않습니다.

콘보 화면의 DOM·CSS와 내부 API를 이용하므로 엔진 화면 구조나 다른 확장·사용자 테마에 따라 표시가 달라질 수 있습니다. 여러 콘보 영역이 동시에 보이는 화면은 지원하지 않습니다. 같은 확장을 중복 활성화하지 마세요.

## 권한과 데이터 처리

이 확장은 **전체 페이지 접근(`full_page_access`)** 권한을 요청합니다. 콘보 화면에 버튼과 창을 넣고 말풍선·배경을 꾸미며 현재 방과 내부 라이브러리를 확인하기 위해 필요합니다. 이 권한은 Marinara 페이지·브라우저 저장소·현재 세션의 내부 API에 접근할 수 있는 강한 권한이므로 실제 코드를 검토하고 승인하세요.

실제 배포 코드의 처리 방식은 다음과 같습니다.

- 현재 방 ID는 브라우저의 `marinara-active-chat-id` 값에서 읽습니다.
- 방별 설정과 프리셋은 Marinara의 **확장 전용 저장소** `convoViewerSettings`에, 창 배치 등은 `convoViewerLayouts`에 저장합니다. 기존 키와 데이터 형식을 유지합니다.
- 현재 Marinara 서버의 `/api/fonts`, `/api/backgrounds`에서 글꼴·배경 목록을 조회하고 서버에 등록된 글꼴·배경 파일을 표시할 수 있습니다.
- 배경 업로드를 선택하면 `/api/backgrounds/upload`로 원본 사진을 보냅니다. 사진에는 위치 등 메타데이터가 남아 있을 수 있습니다.
- 코드에 GitHub·분석 서비스 등 **별도 외부 서버로 데이터를 보내는 요청은 없습니다**. Marinara 서버가 원격에 있다면 사진과 설정은 그 서버에 저장됩니다.
- 메시지는 화면 표시를 위해 읽고 꾸미며, 원본 대화 내용·캐릭터 카드·엔진 설정을 수정하는 요청은 하지 않습니다.

확장을 꺼도 저장한 방 설정·프리셋은 남습니다. 확장을 삭제하면 엔진의 확장 저장소 삭제 정책이 적용되므로 필요한 프리셋은 먼저 내보내세요. 배경 라이브러리에 올린 사진은 확장 끄기·초기화만으로 삭제되지 않습니다.

## 업데이트와 공개 수정 기록

GitHub 확장 관리자로 설치한 경우 해당 확장의 **업데이트 확인 → 업데이트 설치**에서 새 내용을 확인하고 갱신합니다. ZIP으로 직접 설치한 경우 새 ZIP을 받아 같은 가져오기 화면에서 같은 이름의 기존 확장을 선택해 업데이트합니다. **Save Disabled Update**가 표시되면 비활성 상태로 업데이트를 저장하는 버튼입니다.

업데이트된 확장은 꺼진 상태로 저장됩니다. **새 JS·CSS·권한을 확인하고 다시 실행을 승인**하세요. 화면 상태가 남아 있으면 새로고침하세요. 기존 방 설정과 프리셋을 사용하도록 저장 키·형식을 유지합니다.

관리자는 기본 브랜치의 실제 JS·CSS·권한 변경으로 코드 업데이트를 판단합니다. 버전 숫자나 README만 바뀐 경우 코드 업데이트로 표시되지 않을 수 있습니다. 저장소의 `manifest.json` 경로와 릴리스 ZIP 파일명 `convo-viewer.personal-extension.zip`은 앞으로도 유지하는 배포 경로입니다.

### v1.3.0 — 최초 공개 배포

- 제공된 최신 로컬 **v1.3.1 ZIP의 JS·CSS를 그대로** 공개합니다. 공개 표시 버전은 배포 요청에 따라 **v1.3.0**으로 맞췄습니다.
- 캐릭터 아바타 숨기기와 기존 방별 설정·프리셋·버튼 이동·창 조절·도킹·모바일 메뉴 기능을 포함합니다.
- 저장소 루트에 manifest·실행 파일을 배치하고 한국어 설치·사용 안내와 고정 이름의 수동 설치 ZIP을 제공합니다.
- 배포 준비에서 바꾼 실행 설정은 manifest의 표시 버전뿐입니다. 확장 이름·runtime·권한·저장 키·JS·CSS는 원본을 유지했습니다.

로컬 v1.3.1을 이미 설치한 경우 v1.3.0은 숫자상 낮아 다운그레이드 경고가 표시될 수 있습니다. 이 최초 공개본의 실행 코드는 제공된 v1.3.1 ZIP과 같습니다. 원본 파일과 기존 설치를 구분해 확인하세요.

## 자주 생기는 문제

| 증상 | 해결 방법 |
| --- | --- |
| 외부 확장 메뉴가 없거나 가져오기가 잠겨 있어요. | 서버의 외부 확장 허용 설정과 위험 구역의 타사 확장 허용을 모두 확인하세요. 원격 관리라면 Admin Access도 확인하세요. |
| GitHub 패키지를 찾지 못해요. | 저장소 주소가 `https://github.com/you2-use/convo-viewer`인지 확인하고 루트 `manifest.json`을 선택하세요. 릴리스 ZIP 가져오기가 제한되면 manifest 방식이나 ZIP 직접 설치를 사용하세요. |
| 설치했지만 버튼이 없어요. | 코드 검토·실행 승인을 마쳤는지, 콘보방인지 확인하세요. 좁은 화면은 `…` 메뉴, 채팅 설정에 넣은 상태는 채팅 설정 안을 확인하세요. 필요하면 새로고침하세요. |
| 방을 나갔다 오니 설정이 돌아왔어요. | 미리보기 뒤 본문 아래 **적용**을 눌렀는지 확인하세요. 프리셋 저장과 방 설정 적용은 별도입니다. |
| 프리셋 저장 버튼이 비활성화되어 있어요. | 선택창에서 기존 프리셋을 고르거나 **새 프리셋**으로 먼저 만드세요. |
| 프리셋 사진이 다른 컴퓨터에서 안 보여요. | JSON에는 사진 파일이 들어 있지 않습니다. 해당 서버에서 사진을 다시 올리고 선택해 적용하세요. |
| 글꼴이 목록에 없어요. | Marinara에 글꼴을 먼저 등록한 뒤 텍스트 탭을 다시 열어 보세요. 서버에서 글꼴 목록을 가져올 수 있는지도 확인하세요. |
| 말풍선 색·모양 또는 분리가 적용되지 않아요. | Bubbles 표시 방식과 **이 방에서 뷰어 사용**을 확인하세요. 서식·생성 중 메시지·여러 화자 말풍선은 분리 대상에서 제외될 수 있습니다. |
| 사진 업로드·설정 저장에 실패해요. | 서버 연결·관리 권한·파일 크기·형식·저장소 용량을 확인하세요. 사진 업로드 후 방 배경 저장에는 적용도 필요합니다. |
| 업데이트 뒤 확장이 꺼졌어요. | 새 코드와 권한을 검토하고 다시 실행을 승인하는 정상 절차입니다. |
| 다른 테마나 엔진 업데이트 뒤 배치가 이상해요. | 확장을 끄고 새로고침해 확인하세요. 해당 엔진 화면 구조에 맞춘 호환성 수정이 필요할 수 있습니다. |

## 파일 구성

```text
convo-viewer/
├─ manifest.json
├─ extension.js
├─ extension.css
└─ README.md
```

확장 설치용 ZIP에는 `manifest.json`, `extension.js`, `extension.css`, `README.md` 네 파일만 포함합니다. 추천 프리셋 ZIP은 릴리스의 **Assets**에서 별도로 내려받습니다. API 키·토큰·개인 설정·사용자 사진·로그·개발용 검수 자료는 포함하지 않습니다.
